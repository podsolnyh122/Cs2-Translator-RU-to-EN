# Cs2-Translator-RU-to-EN

Локальный переводчик сообщений для Counter-Strike 2. Автоматически переводит ваши русские сообщения в чате на английский язык. Работает через чтение игровых логов, не инжектится в память игры и полностью безопасен для VAC.

> ⭐ **План развития:** При достижении **3 звёзд** (Stars) на репозитории добавлю версию скрипта с поддержкой облачных API для перевода (Яндекс, Google и др.).

## Как это работает
Скрипт в реальном времени читает файл `console.log`. Когда вы отправляете сообщение на русском языке, утилита сначала прогоняет его через базу быстрых замен `dictionary.txt` (для игрового сленга и позиций), а оставшийся текст переводит с помощью локальной нейросети `argostranslate`. После этого готовый перевод записывается в `translate.cfg` и отправляется в игру эмуляцией нажатия клавиши.

## Фичи
* **Полная безопасность** — никаких читов и вмешательства в процессы игры, бан получить невозможно.
* **Внешний словарь** — сленг, маты и позиции вынесены в `dictionary.txt`, их можно менять прямо на ходу без редактирования кода.
* **Поддержка капса** — если вы кричите в чат капсом (например, ДАЙ БОМБУ), перевод будет отправлен тоже капсом (GIVE BOMB).
* **Автоматический ник** — скрипт умеет сам находить ваш текущий никнейм в настройках Steam.
* **Конфиг через .env** — все настройки (пути, клавиши, режимы) удобно вынесены в отдельный файл.
* **Быстрый повтор** — если нажать на триггер-кнопку (по умолчанию F8), в чат повторно отправится последнее переведённое сообщение, что удобно для спама инфы.

## Установка и запуск

1. Установите необходимые библиотеки для Python:
   ```bash
   pip install keyboard argostranslate
   ```
2. В параметрах запуска CS2 в Steam обязательно добавьте команду:
   ```text
   -condebug
   ```
   *(Это необходимо, чтобы игра записывала чат в файл console.log)*
3. Скопируйте файл `.env.example` и переименуйте его в `.env` в папке со скриптом. Настройте пути и параметры под себя. Пример заполнения:
   ```text
   MY_NICKNAME=p0d$0lnyh
   CSGO_DIR=C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo
   TRIGGER_KEY=f8
   AUTO_STEAM_NICK=true
   DEFAULT_ACTIVE=true
   ```
4. Откройте CS2, зайдите в консоль (на кнопку `~`) и привяжите триггер-клавишу (по умолчанию `F8`):
   ```text
   bind f8 "exec translate.cfg"
   ```
5. Запустите переводчик:
   ```bash
   python translator.py
   ```

## Команды управления
Команды можно писать прямо в игровой чат:

* `!translate off` — полностью отключить автоматический перевод сообщений.
* `!translate on` — включить автоматический перевод обратно.
* `!tstatus` — вывести текущий статус работы переводчика в чат игры.
